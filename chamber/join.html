Membership Levels

Non-Profit Level

Non-Profit Level

This is for our non-profit organizations that join us.
There is no fee for this level of membership.
Benefits include:
- Events on the calendar
- Directory Listing
- Home page spotlight
- Recognition and advertising online and around the city
- All events, including VIP events
- Special charity fundraising events
If this sounds like what you need, then sign up for this level.

Bronze Level

Bronze Level

This is the basic membership package.
The annual fee is $350 for this level.
Benefits include:
- Events on the calendar
- Directory Listing
- General events
If this sounds like what you need, then sign up for this level.

Silver Level

Silver Level

This is the intermediate membership package.
The annual fee is $600 for this level.
Benefits include:
- Events on the calendar
- Directory Listing
- General and networking events
- Home page spotlight
- Job postings in events tab on home page
If this sounds like what you need, then sign up for this level.

Gold Level

Gold Level

This is the elite membership package.
The annual fee is $1,000 for this level.
Benefits include:
- Events on the calendar
- Directory Listing
- Home page spotlight
- Recognition and advertising online and around the city
- All events, including VIP events
If this sounds like what you need, then sign up for this level.
